# 文献列表备注

适用于 Zotero 10.0.x。给文献设置一条简短备注后，主文献列表的「标题」列会显示备注。没有备注的文献仍显示原题。

## 安装与使用

1. 在 Zotero 中打开「工具」→「插件」，点击齿轮，选择「从文件安装插件」，打开 `zotero-list-remarks-1.0.0.xpi`。
2. 在文献列表中右键单篇文献，选择「添加列表备注…」，填写并确定。
3. 再次右键可选「编辑列表备注…」。清空内容并确定即可恢复原题。长备注可以把鼠标悬停在文字上查看。

备注保存在当前 Zotero 配置中，仅在本机使用。文献元数据、标题搜索、排序和引用继续使用原题。插件支持普通文献条目，附件、子笔记和订阅条目沿用 Zotero 的显示方式。

## 打包

从 `addon` 目录运行 `zip -q ../zotero-list-remarks-1.0.0.xpi manifest.json bootstrap.js`。
